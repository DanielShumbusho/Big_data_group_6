# Big Data Group 6 – Group Assignment 1 📘

Overview
This project is the first group assignment for the Big Data course, collaboratively developed by Group 6. It explores and demonstrates core big data processing workflows using Python within a Jupyter Notebook (Group_assignment_1.ipynb).

# Key Objectives

Write two functions which are:

# A Palindrome checker

Checks if a string is a palindrome by removing empty spaces and
reversing the string

# A text string combiner

Which combines two user entered strings and combines them into one

# Technologies Used

Python 3.13.2

Jupyter Notebook

Running the Notebook

# To reproduce the results:

Clone the repository:

git clone https://github.com/DanielShumbusho/Big_data_group_6.git
Navigate into the folder:

cd Big_data_group_6/Group_assignment1

Launch Jupyter:

jupyter notebook
Open and run all cells in Group_assignment_1.ipynb.
